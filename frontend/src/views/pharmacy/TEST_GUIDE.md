# 药剂师工作台 - 快速测试指南

## 🎯 测试目标

验证「处方接收与药品发放」功能模块的完整流程，确保所有交互逻辑正常工作。

## 📋 测试前准备

1. **启动前端服务**
   ```bash
   cd frontend
   npm run dev
   ```

2. **访问页面**
   - 打开浏览器访问：`http://localhost:5173`（或实际端口）
   - 使用药师账户登录

3. **进入药剂师工作台**
   - 导航到：药房工作台
   - 确认页面正常加载

### 场景5：扫描药品监管码

**前提条件：** 选择一个"已接收"状态的处方（如 RX202606230003）

**步骤：**
1. 在"扫描药品监管码"输入框中输入药品名称前缀（如"头孢"）
2. 按回车键

**预期结果：**
- 如果匹配成功：
  - 显示"✓ 匹配成功"（绿色）
  - 自动勾选"药品名称一致"复选框
  - 弹出成功提示

  - 显示"✗ 不匹配"（红色）

**测试用例：**
- 输入"头孢" → 应匹配成功（处方中有"头孢克肟分散片"）
- 输入"青霉素" → 应匹配失败（处方中无此药品）

## 🐛 常见问题排查

### 问题1：处方列表为空
**可能原因：**
- API接口未配置
- 模拟数据加载失败

**解决方法：**
- 检查控制台是否有错误
- 确认 `loadMockData()` 函数被调用

### 问题2：扫描验证始终失败
**可能原因：**
- 输入的监管码格式不正确
- 验证逻辑过于严格

**解决方法：**
- 使用处方中药品名称的前2个字符作为测试
- 检查 `verifyDrugCode()` 函数逻辑

### 问题3：发药按钮无法点击
**可能原因：**
- 四项确认框未全部勾选
- 扫描验证未通过
- 处方状态不是"已接收"

**解决方法：**
- 检查所有条件是否满足
- 查看控制台是否有错误提示

### 问题4：超时提醒不显示
**可能原因：**
- 时间计算逻辑错误
- 定时刷新未启动

**解决方法：**
- 检查 `isTimeout()` 函数
- 确认定时器正常运行

## 🎓 培训要点

### 对药剂师的培训
1. **操作流程**：
   - 先看左侧队列 → 点击处方 → 核对信息 → 确认接收
   - 扫描药品码 → 扫描就诊码 → 勾选四项 → 确认发药

2. **注意事项**：
   - 过敏史必须仔细核对（红色高亮）
   - 超时处方优先处理（黄色闪烁）
   - 四项确认缺一不可

3. **异常处理**：
   - 信息有误时使用"异常上报"
   - 网络异常时使用"手动同步"
   - 离线时可手工登记处方

### 对开发人员的培训
1. **代码结构**：
   - 主组件：PharmacyWorkbench.vue
   - 模拟数据：mockData.ts
   - API接口：需对接后端

2. **核心逻辑**：
   - 超时检测机制
   - 扫描验证逻辑
   - 发药条件判断
   - 操作日志记录

3. **扩展开发**：
   - 如何添加新的验证规则
   - 如何自定义超时时间
   - 如何集成真实API
